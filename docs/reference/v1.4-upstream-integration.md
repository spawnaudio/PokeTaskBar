# PokeTaskBar v1.4 integration

## Source and preservation

The fork was copied from PokeTokenBar at `09fd6003` (v2.5.4) into a separately
initialised repository. The v1.4 update integrates the 13 upstream commits through
[`a91076769971644f47b1aeda25bfd26aa564c94a`](https://github.com/chattymin/PokeTokenBar/commit/a91076769971644f47b1aeda25bfd26aa564c94a).

All existing app work was committed in `f38288d0` before integration, with an
additional local archive and SHA-256 inventory. No original workspace files were
removed. Overlapping source files were merged against the copied upstream baseline,
normalising the product/module path to `PokeTaskBar`. Changes to usage UI were
ported into `UsageTabView.swift` and `PopoverChrome.swift`, where this fork moved them.
The original upstream app tree is not added to the fork.

The upstream parent is recorded on the integration branch after the translated
changes are applied. Master follows the repository's squash-PR workflow; use the
upstream SHA above as the baseline for the next translated import, rather than
assuming matching source paths or shared history.

## Included upstream changes

- Additional per-model usage, refreshed pricing, zero-token provider filtering,
  safer token counts, CLI/IDE token discovery, and credential refresh fixes.
- Quota pace markers and translated Antigravity group names.
- Skipped update controls and a quick floating-pet toggle in the shared footer.
- Hatch retry messaging and asynchronous prefetch protection.
- Bulk Rare Candy selection with consumption and growth previews.
- Unown forms, individual sprites, collection details, and representative selection.

## Fork behaviour retained

The main window, Today desk, custom menu-bar shell, continuous scrolling collection,
floating focus timer, and static Pokéball menu icon remain. XP reward feedback
continues to show `+XP` in the menu bar and next to the pet, with a fading screen edge;
see [XP feedback](xp-feedback.md).

Coins remain XP divided by 1,000. Rare Candy still grants 1.5M XP per candy, Mint
still doubles earned XP for 30 minutes, purchases put eggs in storage, graduation
provides a free training egg, and duplicate normal catches re-roll. Unown checks
normal duplicates by letter; new letters are collectible. Storage swaps clear the
previous egg's pending letter and retry message. Newly imported tests use these
fork rules instead of upstream's 100M candy and nature-changing Mint assumptions.
Existing unrelated behaviour and its test expectations were not rewritten.

## Local build and reset

`bash scripts/rebuild-v1.4.sh` builds version **1.4.0**, named **PokeTaskBar v1.4**.
Set `PTB_SKIP_INSTALL=1` to assemble without installing. Its bundle identifier is
`io.github.spawnaudio.poketaskbar.v1.4` and it uses its own Application Support folder.
This is a local app build; no public GitHub Release is published by this script.

The requested one-time upgrade saved a private recovery copy of the previous app,
state, and preferences, copied settings and saved connections, and reset game and
focus history. Historical token and Linear data seed fresh baselines without
re-awarding old work. External Linear issues and provider usage records are unchanged.
Launch verification found version 1.4.0 running with zero caught Pokémon, storage,
inventory, tokens, and bonus XP; both historical baselines had been seeded. The
replaced v1.3 app was removed from Applications after the recovery copy was verified.
