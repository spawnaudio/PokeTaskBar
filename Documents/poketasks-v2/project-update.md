# PokeTasks v2

**PokeTasks v2 is currently in planning mode.** The next build preserves the current Linear-style issue/project/initiative cards and refines window/tab behavior: folded icon navigation, independently folded panels and task sections, rounded scroll boundaries, scoped context menus, and restrained reveal/folding motion. Time Blocking and task time tracking with scores and a GitHub-style heatmap remain planned.

[Locu](https://locu.app) is the main workflow reference. The resting floating bar shows only title and time; hover/focus actions are planned to replace the title within the same bar bounds, with a fixed clock anchor. Document/note syncing remains a low-priority backlog item.
