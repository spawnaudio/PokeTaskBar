# Pokémon-type themes

Screen mockups and matching UI component sheets for the 18 standard Pokémon types, using the [official Pokémon type chart](https://sg.portal-pokemon.com/game/type-chart/) as the type inventory. These are original visual directions for PokeTaskBar, not official Pokémon interface designs.

## Scope

Every type gets the same Focus workflow and twelve component groups: actions, navigation, text inputs, choice controls, rows/inspector, badges/status, progress/score, companion/items, focus timer, floating chrome, feedback/confirmation, and empty/loading/log states. Palette and typography samples appear above the groups.

The eight earlier style themes already have [component breakdowns](../components/README.md). They remain available and are not replaced by this set.

These are static image mockups generated with the built-in Image Gen tool. Native behaviour, actual-size readability, contrast, and the final labels/icons still need validation during implementation. The illustrative Pokémon are theme examples; users should still be able to choose their own companion independently of a theme.
