# Theme concepts

[Consolidated Linear document — proposal, 26 themes, and all 52 images](https://linear.app/spawn-audio/document/poketaskbar-themes-proposal-mockups-and-ui-library-a8fe84dca210)

Five additional PokeTaskBar theme explorations, generated on 2026-09-18 with the built-in Image Gen tool. These are visual concepts, not implemented screens. They use the previous Classic concept as the layout and content reference.

- [Pokédex](pokedex.png)
- [Midnight Observatory](midnight-observatory.png)
- [Paper Journal](paper-journal.png)
- [Ocean Glass](ocean-glass.png)
- [Neon Arcade](neon-arcade.png)

The same task, timer, and companion are used to compare the visual treatments. [Generation prompts](prompts.md) are retained for refinement.

[Component mockups for all eight themes](components/README.md) explore the shared controls, forms, navigation, cards, timers, and feedback states.

[Pokémon-type themes](pokemon-types/README.md) contain screen concepts and matching UI breakdowns for Normal, Fire, Water, Electric, Grass, Ice, Fighting, Poison, Ground, Flying, Psychic, Bug, Rock, Ghost, Dragon, Dark, Steel, and Fairy.
